# Secure Door

**Source:** https://lethal-company.fandom.com/wiki/Secure_Door

## Overview

Secure Doors are terminal-controlled doors found within the Facility interior in *Lethal Company*. Each is labelled with a short code (for example "m6") visible on the radar map, and typing that code at the ship's terminal toggles the door open or closed. Because entities cannot open them, Secure Doors are the crew's most reliable tool for locking dangerous creatures away.

## Key Points

- Operated by typing the door's **designated name/code** at the terminal.
- **They must have power to operate.** An inoperable door's name appears in a **darkish green** on the terminal.
- Power is lost when a **Breaker Box is switched off** or the **Apparatus is removed** — after which the doors cannot be controlled at all.

## Important Details

### Duplicate names

**If two Secure Doors share the same name, both respond simultaneously to a terminal command.** For example, two doors designated "X9" both toggle when that code is entered. If one is open and one is closed, entering the code **reverses both states** rather than synchronizing them.

### Entity blocking

**Secure Doors cannot be opened by entities.** This makes them a hard counter: dangerous entities such as the **Coil-Head** or **Jester** can be sealed behind one, nullifying their threat entirely — provided the door stays closed.

**The Ghost Girl is the exception — she phases straight through.**

### Recommended use

Close doors leading to empty rooms or hallways that contain a **vent**. Entities spawning from a sealed vent are prevented from roaming the rest of the facility, which meaningfully reduces the number of active threats a crew has to handle.

## Warnings

- Losing power — whether by breaker or by taking the Apparatus — is **irreversible for door control** unless power is restored. Removing the Apparatus permanently kills interior power, so any entity sealed behind a Secure Door is released the moment that happens.
- Because Secure Doors only exist in the Factory layout, this strategy is unavailable in Mansion and Mineshaft interiors.
