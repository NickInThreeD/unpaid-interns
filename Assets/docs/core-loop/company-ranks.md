# Company Ranks

**Source:** https://lethal-company.fandom.com/wiki/Company_Ranks

## Overview

Company Rank is *Lethal Company*'s persistent progression indicator, conveying an employee's overall experience level across sessions. Rank is driven by XP: strong mission grades award XP and lead to promotions, while poor grades and failed missions deduct XP and can cause demotions. Rank is cosmetic — it does not grant gameplay bonuses.

## Key Points

- XP is earned from **mission grades** (the letter grade on the end-of-day Performance Report).
- Poor grades and failures **subtract** XP, so rank can move downward as well as upward.
- Rank is displayed as a sticker/badge associated with the employee.

## Rank Progression

| Rank | XP required |
|---|---|
| Intern | Entry level |
| Part-Timer | 50 XP |
| Employee | 100 XP |
| Leader | 200 XP |
| Boss | 500 XP |

**Boss** is the highest documented rank, reached at 500 XP.

## Important Details

There was a known overflow issue where accumulating very high XP wrapped the player's rank back around. Surpassing **1,500 XP** no longer resets an employee to Intern — this was **patched in v81**.
