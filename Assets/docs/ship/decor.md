# Decor

**Source:** https://lethal-company.fandom.com/wiki/Decor

## Overview

Decor is any decorative element aboard the autopilot ship in *Lethal Company*, covering both movable furnishings and employee suits. Beyond cosmetics, decor matters mechanically because **furniture placed in the ship contributes "quota luck"** that reduces the size of the next profit quota increase. This page covers what comes standard, how decor is moved and stored, and the purchase catalogue.

## Key Points

- **Standard issue on every ship:** Bunkbeds, File Cabinet, Cupboard, and the Decoy Suit.
- Everything else is bought from the **Company Store** — with the exception of the **Purple Suit**, which is granted by default on Challenge Moons.
- Purchased decor is **unlocked for the entire remainder of a crew's contract**.
- **A crew cannot purchase duplicates** of the same decor item.

## Handling Decor

All furnishings **except Cozy Lights** can be:

- **Moved** — default key [B]
- **Rotated** — default key [R]
- **Hidden** — default key [X]

Hidden items are retrieved by typing `STORAGE` at the terminal.

The **Terminal** and **monitors** behave similarly to decor but are fundamental to the crew's duty and **cannot be hidden**. The four ship upgrades sit in the same category.

## Store Rotation

Typing `STORE` or `DECOR` at the terminal lists decor currently available for purchase. **Only a limited selection is available at any one time, and the stock rotates each quota period** — so a wanted item may simply not be buyable this cycle.

## Quota Luck

The reason to buy decor is not purely aesthetic. Furniture in the ship contributes to `totalLuck`, which is subtracted from the quota randomizer input and lowers the expected quota increase. The **Disco Ball is by far the strongest contributor (0.06)**, followed by the Television (0.02) and Shower (0.015). The **Signal Translator is the only item with negative luck (-0.012)** and should be kept out of a luck-optimized ship.

Note the timing rule: **furniture placed during quota *n* only affects the luck calculation for quota *n + 1*.** See the Profit Quota page for the full formula and per-item values.
